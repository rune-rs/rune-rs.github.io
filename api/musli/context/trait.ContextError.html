Trait governing errors raised during encodeing or decoding.

fn message<T>(alloc: A, message: T) -> Self
where T: Display,

Collect an error from something that can be displayed.

This is made available to format custom error messages in no_std environments. The error message is to be collected by formatting T.

fn traced_message<T>(alloc: A, message: T, location: &Location<'_, A>) -> Self
where Self: Sized, A: Allocator, T: Display,

Collect an error from something that can be displayed, which was raised at the given Location.

A context which traces, such as one built with DefaultContext::with_trace, calls this instead of ContextError::message. The default implementation passes the message decorated through Location::with_message to ContextError::message, so that the Display of the error includes the path and position, such as .field[2].name: Expected string (at byte 14).

Source

fn traced_custom<T>(alloc: A, error: T, location: &Location<'_, A>) -> Self
where Self: Sized, A: Allocator, T: 'static + Send + Sync + Error,

Construct a custom error, which was raised at the given Location.

A context which traces, such as one built with DefaultContext::with_trace, calls this instead of ContextError::custom. The default implementation formats the error decorated through Location::with_message and passes it to ContextError::message, which keeps the location but not the original error. Implementations which can keep the error as a source should override this.
