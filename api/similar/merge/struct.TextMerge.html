Struct TextMerge 

Source 
pub struct TextMerge<'base, 'ours, 'theirs, T: DiffableStr + ?Sized> { /* private fields */ }
Expand description

The result of a line-oriented three-way merge.

The result retains all three inputs and represents merged regions as ranges into them. Formatting the value produces the merged text and inserts conflict markers for unresolved regions.
