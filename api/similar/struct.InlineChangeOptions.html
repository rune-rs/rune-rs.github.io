Struct InlineChangeOptions 

Source 
pub struct InlineChangeOptions { /* private fields */ }
Expand description

Configuration for inline refinement in TextDiff::iter_inline_changes.

Defaults:

  • algorithm: Algorithm::Patience
  • mode: InlineChangeMode::Auto
  • min ratio: 0.5
  • semantic cleanup: disabled

Sets the minimum ratio required to apply inline refinement.

If the initial rough ratio or refined ratio drops below this threshold, the operation falls back to non-emphasized line changes.

pub fn semantic_cleanup(&mut self, yes: bool) -> &mut Self

Enables a semantic cleanup pass for refined inline ops.

This performs extra boundary shifting and overlap extraction intended to improve human readability of intraline highlights.

Disabled by default.
